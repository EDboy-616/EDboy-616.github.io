两台电脑，一个博客

办公电脑上改，回家也能接着改。所有版本都存在 GitHub 上， 换哪台电脑、在哪个城市，都能从同一个最新版继续。

原理：GitHub 是中间那个柜子

办公电脑改完推上去
⇄push
GitHub唯一的存档处
⇄pull
家用电脑开工先拉下来

两台电脑不直接连接，都只跟 GitHub 打交道。谁先改了谁推上去，另一台拉下来就同步了。

日常只有两步

  1. 坐下开工前，双击 开工前先双击这个.bat

    从 GitHub 取回最新版本。这一步能防止你在一台电脑上改的是旧版。

  2. 改完要上线，双击 发布博客.bat

    自动提交、推送到公开站点和私人备份两处。约一两分钟后刷新 edboy-616.github.io 就能看到。

最重要的一条

同一时间只在一台电脑上改。 改完就推，换电脑先拉。只要守住这条，几乎永远不会出乱子。

回家第一次：只拷一个文件

另一台电脑上还没有这个项目，需要先把它弄下来。做法：

  1. 把 在家第一次用-双击这个.bat 拷到家里电脑

    U 盘、微信「文件传输助手」、邮件给自己，都行。

  2. 在家用电脑上双击它

    它会自动检查有没有装 Git（没装会告诉你怎么装）、把整个项目下载到 C:\Users\你的名字\blog、配好私人备份地址。

  3. 以后就在那个文件夹里，照常双击那两个脚本

    和办公电脑完全一样。这个说明页也会跟着一起下载过去。

前提

家里电脑要先装 Git。没有的话，在 PowerShell 里粘贴这一行回车：

winget install --id Git.Git -e

或者去 git-scm.com 下载 Windows 版，一路下一步。

第一次发布会让你登录一次

下载公开仓库不用登录，但推送到你的私人备份要验证身份。 第一次双击「发布博客」时，会弹出浏览器让你授权 GitHub 账号，用 EDboy-616 授权一次，以后不再问。

Everything

找不到 Git 新电脑没装 按上面「前提」那节装一次

加新页面（作品集等）

都放在这个项目里，建子文件夹分类即可，不用另开仓库：

portfolio/index.html → edboy-616.github.io/portfolio/
notes/index.html → edboy-616.github.io/notes/

页面里引用样式统一写 /assets/style.css，全站共用一份，加载快。
