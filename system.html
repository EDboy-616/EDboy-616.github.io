I. 框架 / FRAMEWORK•三段时间，一个方向 01 / 07
交易框架 THREE CLOCKS

只做趋势的中段。

周线定身份，日线验力度，小时找位置。三段时间讲不出一致的故事，就不下单。

II. 原则 / PRINCIPLES•判断的顺序 02 / 07
判断方式 STATE, NOT SNAPSHOT

看状态量，
不看快照。

任何一个指标，都不能孤立地看当前值。它在哪、怎么走到这里、在整体里意味着什么——三件事合起来，才是一个判断。

01

位置

价格现在站在结构的哪一侧：均线之上还是之下，区间之内还是之外，通道的哪一段。

Where it is
02

过程

它是怎么走到这里的：斜率在抬升还是走平，动能柱在扩张还是收缩，回踩是变浅还是变深。

How it got here
03

结构

放到更大的周期里，它意味着什么。周线的身份，决定小时级的信号算不算数。

What it means

判断顺序：位置 → 过程 → 结构。缺一不可。

III. 三关 / THREE GATES•都过才动手 03 / 07
执行顺序 IDENTITY → FORCE → LOCATION

三关都过，
才动手。

周线回答“能不能做”，日线回答“够不够强”，小时回答“在哪里做”。任何一关说不，结论都是等。

第一关 / WEEKLY

周线 · 身份门

定势 / Identity
  • 均线排列与斜率必须同向；方向或排列对不上，就是缠绕。
  • 缠绕期不开仓。这里没有“先小仓试试”的通道。
  • 排列只给资格，不给入场时间；它天然滞后，所以主动放弃鱼头。
不通过空仓等待
第二关 / DAILY

日线 · 力度

验证 / Force
  • 方向对了还不够，趋势强度必须正在爬升。
  • 强度不足时，周线方向只是背景，不是入场许可。
  • 力度看过程：连续抬升，比单根读数可靠。
不通过只观察，不进场
第三关 / HOURLY

小时 · 位置

执行 / Location
  • 等回调走到通道或结构位，不在突破的当下追价。
  • 反转形态、位置、动能三样对齐，才构成一次入场。
  • 信号出现后下一根再进；跳离回调区，信号作废。
不通过放弃这一笔
确认分层

周线信号周中即算数；日线等当根收盘；小时必须等这根走完。周期越快，确认越严——这是这套框架唯一不妥协的节奏。

IV. 否决 / VETO  ·  系统先学会说不 04 / 07

系统先学会说不。

大多数亏损，不是因为看得不够多，而是因为在该说不的时候，给自己找了一个理由。

01

缠绕期不开仓

方向没有身份，任何仓位都是在替市场做决定。等它自己走出排列，而不是替它选择方向。

02

结构破位不做多

价格握有最终否决权。只破一条均线不算破位；破了结构，就不再找入场。空头侧同理，不摸顶。

03

清仓不等于反手

变盘只说明原来的故事结束了。要不要反向，重新走完整判定流程，不把平仓当成新信号。

排列是确认性指标，天然滞后。
主动放弃鱼头，只吃鱼身鱼尾。

V. 风险 / RISK•先定价，再下注 05 / 07
风险顺序 RISK BEFORE REWARD

先给错误定价。

止损不是认错，是提前给判断失误标一个价格。价格合理，错误就只是成本。

  • 01
    止损放在结构失效处

    不是心理舒服处。结构位与波动幅度共同决定，超出预算就收紧到预算内。

  • 02
    仓位由公式决定

    不由信心决定。算出来是零，就不做；也不为了凑一手去破风险上限。

  • 03
    保护线只朝一个方向移动

    日线不创新高、也不创新低，线就不动；已经挂出的线不回改。

  • 04
    离场有先后

    预挂单先于盘中变盘，盘中变盘先于收盘指标。顺序就是纪律。

VI. 边界 / BOUNDARY•这套框架不做什么 06 / 07
方法的另一半 WHAT IT REFUSES

它也不做什么。

一个方法的价值，一半来自它允许你做什么，另一半来自它禁止你做什么。

做 / DOES

把能控制的部分做到位

  • +等排列成立
  • +等日线收盘
  • +等小时形态走完
  • +按公式下注
  • +把错误写下来
不做 / DOES NOT

不为冲动留后门

  • −不预测点位
  • −不喊单
  • −不补仓摊平
  • −不逆势摸顶
  • −不在缠绕期试仓
  • −不因一次盈利改规则
